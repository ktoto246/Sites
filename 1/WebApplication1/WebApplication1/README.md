# АгроКонтроль — локальная система ТО и ремонта сельхозтехники

Учебное веб-приложение для курсовой работы. Работает на одном компьютере и хранит данные в локальной базе SQLite `maintenance.db`.

## Функции

- реестр сельскохозяйственной техники и закреплённых трактористов;
- регистрация заявок на неисправности;
- назначение механиков и контроль статусов ремонта;
- планирование технического обслуживания;
- учёт складских остатков и закупок запчастей с поставщиками и номерами документов;
- отчёты с показателями и графиками;
- демонстрационные роли: администратор, диспетчер, механик.

## Запуск

```powershell
cd "D:\GitHub\Курсовые\1\WebApplication1\WebApplication1"
dotnet run
```

После запуска приложение откроется по адресу, который выведет консоль (обычно `http://localhost:xxxx`).

Для демонстрации ролей наведите курсор на блок «Текущая роль» в боковом меню и выберите администратора, диспетчера или механика.
