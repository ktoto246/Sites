## 📂 Как найти информацию о проекте

Каждый проект имеет **свой `README.md`** в папке. Там написано:
- 📝 Описание проекта
- 🛠️ Используемые технологии
- 🚀 Как запустить
- ⚙️ Требования и настройка

**Просто откройте папку проекта и прочитайте его `README.md`**

## 🎯 Быстрый старт

### Требования (общие)
- **Веб-браузер** (Chrome, Firefox, Edge, Safari)
- **Текстовый редактор** (VS Code, Sublime, и т.д.) — для редактирования кода
- **Node.js** (если используется) — для проектов с backend
- **Локальный сервер** (если требуется) — Live Server, python, и т.д.

### Как запустить сайт

Зависит от типа проекта:

#### 1️⃣ Статический сайт (HTML/CSS/JS)
```
1. Откройте папку проекта
2. Откройте файл index.html в браузере
   ИЛИ используйте Live Server в VS Code
```

#### 2️⃣ Динамическое приложение (React, Vue, и т.д.)
```
1. Откройте папку проекта в терминале
2. npm install
3. npm start
```

#### 3️⃣ Приложение с Backend
Смотрите `README.md` в папке проекта для специфических инструкций
