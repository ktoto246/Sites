# 🌐 Web Projects — Fullstack .NET Development

Репозиторий содержит мои веб-проекты: от проектирования баз данных и написания REST API на **ASP.NET Core** до верстки клиентской части на **HTML/CSS/JS**. 

Вместо шаблонных учебных задач здесь лежат реальные системы с ролевой моделью, авторизацией и работой с БД.

---

## 🚀 Ключевые проекты

| Проект | Описание | Стек технологий |
|---|----------|-----------|
| 🌾 **[БХБ (Балашовская хлебная база)](./дипломный)** | Комплексная система управления хранилищем, доставкой и финансами. Реализованы 4 роли (клиент, диспетчер, админ, финансист). | ASP.NET Core 8, Dapper, SQL Server, HTML5, CSS3, JS, Bootstrap |

> **Как запустить и посмотреть код:**
> Проваливайтесь в папку конкретного проекта (например, `/дипломный`). Там лежит свой локальный `README.md` с подробным описанием архитектуры, инструкцией по развертыванию БД и запуску бэкенда.
